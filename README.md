# Aplikasi Booking Servis Motor (Bengkel Royal Motor)

Aplikasi berbasis web untuk memudahkan pelanggan melakukan booking jadwal servis motor dan membantu admin mengelola status pengerjaan servis.

## Fitur Utama
- **Autentikasi User & Admin**: Hak akses terpisah untuk pelanggan dan pengelola bengkel (Login / Register).
- **Form Booking Servis**: Pelanggan dapat mengajukan jadwal servis dan menyampaikan keluhan kendaraan.
- **Batalkan Booking**: Fitur pembatalan pesanan langsung oleh pelanggan.
- **Dashboard Admin**: Pengelolaan status booking (Menunggu, Disetujui, Selesai) dan penentuan mekanik.

## Teknologi yang Digunakan
- **Framework**: Laravel 12
- **Bahasa Pemrograman**: PHP & JavaScript
- **Styling**: Tailwind CSS
- **Database**: MySQL
